
A **Caesar cipher** is one of the simplest encryption methods. It works by **shifting each letter of the alphabet by the same number of positions**.

### Example: Shift = 3

Plaintext:

```
HELLO
```

Move every letter **3 places forward**:

- H → I → J → **K**
- E → F → G → **H**
- L → M → N → **O**
- L → **O**
- O → P → Q → **R**
