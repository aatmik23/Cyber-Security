
two widely used incident response frameworks: SANS and NIST

SANS incident Response framework has 6 phases, which can be called 'PICERL' to remember them easily.

| Phase               | Short Explanation                               | Example                                      |
| ------------------- | ----------------------------------------------- | -------------------------------------------- |
| **Preparation**     | Prepare people, plans, and security tools.      | Train employees to identify phishing emails. |
| **Identification**  | Detect and analyze suspicious activity.         | Detect unusual data transfer from a host.    |
| **Containment**     | Limit the attack and prevent it from spreading. | Isolate the compromised computer.            |
| **Eradication**     | Remove the threat from the system.              | Scan and remove malware.                     |
| **Recovery**        | Restore systems and return them to normal.      | Restore data from backups.                   |
| **Lessons Learned** | Review the incident and improve security.       | Analyze the root cause and improve defenses. |
