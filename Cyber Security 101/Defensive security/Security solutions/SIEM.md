
### SIEM Features

- **Centralized Log Collection:** Collects logs from all devices in one place.
    
- **Log Normalization:** Converts different log formats into a consistent format. **Parsing** = breaking logs into fields.
    
- **Log Correlation:** Connects events from different sources to detect suspicious activity.
    
- **Real-time Alerting:** Detects threats and alerts analysts immediately.
    
- **Dashboards & Reporting:** Displays alerts, failed logins, events, triggered rules, and other security information.
