**Workstations**

A **workstation** is a high-performance computer designed for professional or technical work that requires more computing power, reliability, and expandability than a typical personal computer.

A **standard user workstation** is a computer intended for **everyday, non-administrative tasks** and **should never have a privileged user signed into it**.

these devices should never have a privileged user signed into them

- Malware on the workstation could steal their credentials.
- An attacker could use those credentials to compromise the entire network.
- It greatly increases the risk of privilege escalation.
