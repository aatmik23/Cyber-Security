

Most Linux distributions use Bash (Bourne Again Shell) as their default shell.

**`ls` is a command.**  
**Bash is the program that understands and runs that command.**


```shell-session
user@tryhackme:~$ pwd
/home/user
```

```shell-session
user@tryhackme:~$ cd Desktop
user@tryhackme:~$/Desktop$
```

```shell-session
user@tryhackme:~$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos
```

```shell-session
user@tryhackme:~$ cat filename.txt
this is a sample file
this is the second line of the file
```

```shell-session
user@tryhackme:~$ grep THM dictionary.txt
The flag is THM
```
