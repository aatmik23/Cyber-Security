
`cd`

without parameters to display the current drive and directory.


`dir`

view the child directories

- `dir /a` - Displays hidden and system files as well.
- `dir /s` - Displays files in the current directory and all subdirectories.

tree

visually represent the child directories and subdirectories.

`type`
command will dump the contents of the text file on the screen;

`copy`

```
copy <source> <destination>
```

- **`copy`** → The command that copies files.
- **`test.txt`** → The **source file** (the file you want to copy).
- **`test2.txt`** → The **destination file** (the new file that will be created).


`move`

delete a file using `del` or `erase`.

character `*` to refer to multiple files.

`copy *.md C:\Markdown` will copy all files with the extension `md` to the directory `C:\Markdown`.
